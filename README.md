# 2026 Global Health Conference Program

This repository is a static archive of the online program for the Fifth Annual Global Health Conference, held September 28–30, 2026 at the Heritage Hotel & Conference Center in Southbury, Connecticut. The program was originally maintained as an actively updated conference website. This GitHub Pages edition preserves the session listings, speaker directory, biographies, photos, and links to available session recordings as a static site.

The site was created and updated with AI assistance, including code generation, layout work, data entry, and preparation of this archive. Conference organizers supplied and reviewed the program details and participant materials. AI assistance should not be treated as an independent source for the biographical or conference information.

## What still works

- Browse and search the three-day program, filter by day, type, room, speaker, panelist, and moderator.
- Open session, sub-session, and speaker profile views through hash-based links.
- Use **My Schedule** on the current device. Selections are stored in that browser's local storage; they are not shared across devices or accounts.
- Watch linked recordings on YouTube. Breakouts 11 and 12 display **Recording Not Available**.

The published site consists of static HTML, CSS, JavaScript, and images. It has no database, server-side login, or automatic updates. The past conference dates mean the time-based live indicator will not become active again. External links remain subject to their destination sites.

## Publish on GitHub Pages

1. Create a GitHub repository and upload the **contents of this ZIP** to the repository root. Commit the source files and the `docs/` directory to the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**. Choose `main` and `/docs`, then save.
4. GitHub Pages will provide a URL such as `https://USERNAME.github.io/REPOSITORY/` after deployment.

The build uses relative asset URLs, so it works at a project URL under `/REPOSITORY/` and at a custom domain. The `docs/.nojekyll` file tells Pages to serve the built assets without Jekyll processing.

## Rebuild after edits

Install Node.js 22.13 or newer, then run from the repository root:

```bash
npm ci
npm run build
```

Commit both the edited source files and the rebuilt `docs/` folder. GitHub Pages serves `docs/` directly; changing only a file in `app/` will not update the public page. For a local development preview, run `npm run dev`. For a preview of the production build, run `npm run preview`.

## Repository layout

| Path | Purpose |
| --- | --- |
| `docs/` | Built site served by GitHub Pages. Generated by `npm run build`. |
| `app/conference-data.ts` | Sessions, sub-sessions, participant names, roles inferred from sessions, and recording links. |
| `app/master-session-content.ts` | Session descriptions and learning objectives. |
| `app/submitted-bios.json` | Most supplied participant biographies. |
| `app/speaker-bios.ts` | Additional biography fallbacks. |
| `app/speaker-titles.json` | Optional professional title or profile-label overrides. |
| `app/submitted-photos.json` | Speaker ID to image-path mapping. |
| `public/speakers/` | Original images copied into `docs/speakers/` on build. |
| `app/page.tsx`, `app/globals.css` | React interface and styling. |

The speaker directory is generated from people named in sessions. A biography or image added for someone who is not assigned to a session will not create a visible directory card. For step-by-step changes to titles, bios, and portraits, see the separate editing guide supplied with this export.
